# TuskeAI

> Think. Build. Solve.

TuskeAI is an open-source, privacy-first AI platform built to become more than a chatbot.

Its mission is to create a modular AI companion that grows together with its user, works both online and offline, and puts people—not algorithms—at the center.

## Vision

- 🧠 Modular AI architecture
- 🔒 Privacy-first design
- 🌐 Offline-first whenever possible
- 🎙️ Voice interaction
- 👁️ Vision capabilities
- 🛠️ Workshop Mode
- 🤝 Open-source collaboration

## Roadmap

- ✅ Chat
- 🚧 Voice
- 🚧 Vision
- 🚧 Workshop Mode
- 🚧 TuskeMind

See **ROADMAP.md** for details.

## Philosophy

Technology should empower people, not replace them.

TuskeAI is built with craftsmanship, curiosity, and respect for its community.
